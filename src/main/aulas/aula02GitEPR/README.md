## Objetivo
Praticar conceitos básicos de Git: fork, clone, correção de bugs e pull request.

## Instruções

### Para quem vai corrigir o código (dupla):
1. Faça um **fork** deste repositório para sua conta do GitHub
2. **Clone** o repositório forkado para sua máquina
3. Abra o arquivo `arquivo.py` e identifique o erro proposital
4. Corrija o erro no código
5. **Commit** as alterações com uma mensagem descritiva
6. **Push** as alterações para seu repositório forkado
7. Abra um **Pull Request** para o repositório original

### Para quem criou o código:
1. Aguarde o Pull Request do seu dupla
2. Revise as alterações propostas
3. Se estiver correto, **merge** o Pull Request
4. Faça o mesmo processo para corrigir o código do seu dupla

## Conceitos aprendidos
- Fork de repositório
- Clone de repositório
- Commit de alterações
- Push para remote
- Pull Request
- Code review
- Merge de alterações
